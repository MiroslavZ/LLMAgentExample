# Разбор задания «День 19: Композиция MCP-инструментов»

## Суть задания

Нужно показать, что агент умеет **автоматически** выполнять **цепочку из нескольких MCP-инструментов** и корректно передавать данные между шагами.

Пример из задания:

1. `search` — получает данные  
2. `summarize` — обрабатывает полученные данные  
3. `saveToFile` — сохраняет итог

---

## Что обязательно должно быть сделано

1. В одном MCP-сервере зарегистрировано несколько tools.
2. Реализован pipeline (последовательный вызов tools).
3. Передача данных между шагами работает корректно.
4. Цепочка запускается автоматически от пользовательского запроса (без ручного дергания каждого шага по отдельности).

---

## Критерии, по которым обычно считают, что задание выполнено

- Агент по запросу сам выбирает нужные инструменты.
- Инструменты вызываются в логически правильном порядке.
- Выход одного инструмента действительно используется как вход следующего.
- Есть итоговый артефакт/результат (например, сохраненный файл, summary, отчет).

---

## Важные уточнения из чата

1. Для 19 дня — **в рамках одного MCP-сервера** (не нескольких).  
   Несколько MCP-серверов и межсерверная маршрутизация — это уже 20 день.

2. Шаблон `search -> summarize -> saveToFile` — это **пример**, а не жесткое требование.  
   Допустима любая осмысленная цепочка инструментов.

3. Ключевая идея — **агентная композиция**: агент сам собирает последовательность вызовов по запросу и описаниям tools.

4. Явно нумеровать инструменты на сервере не надо, надо, чтобы порядок следовал из смысла задачи и контрактов инструментов (LLM из полученного промпта сама делает вывод что в каком порядке вызвать).

---

## Как 19 день зависит от 16–18

### День 16 (подключение MCP)
- База: есть MCP-соединение и получение списка доступных инструментов.

### День 17 (первый MCP-инструмент)
- Уже есть практика: регистрация инструмента, схема параметров, вызов из агента, получение результата.

### День 18 (планировщик/фоновые задачи)
- Может дать готовые части (хранилище, агрегирование, сохранение), но cron/24x7 для 19 дня не обязателен.

Итого: 19 день — это переход от «один инструмент» к «композиции нескольких инструментов в автоматический pipeline».
