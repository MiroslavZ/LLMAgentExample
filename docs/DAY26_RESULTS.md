# День 26 — локальная LLM

Проверка выполнена 9 октября 2026 года (Asia/Yekaterinburg).
Использован уже установленный LM Studio на другом компьютере локальной сети:
`http://192.168.1.188:1234/v1`. Новая установка и скачивание весов не требовались.

`GET /v1/models` через библиотеку `openai` вернул модель
`gemma-4-26b-a4b-it-qat`. Все запросы генерации отправлялись только ей,
без токена и без облачного API. Qwen не загружался и не вызывался.

| Сложность | Запрос | Результат | Время |
| --- | --- | --- | --- |
| Простой | `17 + 25`, только число | `42` | 2,29 с |
| Средний | Отличия list/tuple с примерами, до 100 слов | Объяснение изменяемости и два примера | 7,54 с |
| Сложный | Функция удаления дублей с сохранением порядка для словарей/списков, 3 теста и сложность | Функция, 3 assert-теста, оценка O(n²) | 9,79 с |

Полные запросы, ответы, выбранное подключение и длительность:
[day26_local.json](evaluation/day26_local.json).
Время включает работу сервиса агента, это один прогон, не сравнительный бенчмарк.
Предварительный первый вызов той же модели занял 22,52 с; последующие запросы
выполнялись с уже загруженной моделью.

Ответы получены через `ConversationService` с изолированным временным каталогом.
Для каждого запроса создавался новый диалог. Основной пользовательский каталог
не заполнялся тестовыми моделями. Дополнительно в браузере проверены импорт
Gemma из LM Studio, выбор модели, ответ `42` на `6 * 7` и сохранение после
перезагрузки страницы.

В отдельном синтетическом диалоге проверено переключение
**Gemma → DeepSeek (`deepseek-chat`) → Gemma**. Все три ответа воспроизвели
кодовое слово «кедр» из первого сообщения: история сохранилась при смене
модели и сервера. Ключ `.env` использовался только для DeepSeek.
Полные результаты: [day26_switch.json](evaluation/day26_switch.json).

Автоматическая проверка: `python -m unittest discover -s tests -q` —
**647 тестов, OK**. Покрыты пустой каталог, CRUD, дубликаты, ошибки сети,
выбор и удаление моделей, совместимость старых диалогов, секреты, маршрутизация
служебных запросов, CLI и веб-интерфейс.

Факт ответа не доказывает безошибочность модели: формулировка про кортежи
упрощена — вложенные изменяемые объекты могут менять своё содержимое, а
обобщение о скорости кортежей зависит от операции. Код третьего ответа
обходит нехешируемость элементов сравнением со списком результата.

## Повторить проверку

```powershell
.\venv\Scripts\python.exe -m llm_agent.local_smoke --base-url http://192.168.1.188:1234/v1 --model gemma-4-26b-a4b-it-qat --output data/day26-repeat.json
```

Выберите новый путь отчёта: скрипт не перезаписывает существующий файл.
Он проверяет присутствие точного ID в `/models`, делает три запроса через
агента и завершается ошибкой при неуспешном или пустом ответе.

При первоначальном подключении системный HTTP-прокси возвращал 503.
Прямое соединение с локальным адресом работало; общий клиент теперь обходит
прокси для локальных IP и `localhost`. Это применяется и к discovery, и к
основным/служебным запросам агента.
