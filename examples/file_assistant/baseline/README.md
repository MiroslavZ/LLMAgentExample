# Учебный обработчик записей

`ApiClient` возвращает тестовые данные из памяти. Реальных HTTP-запросов нет.

Настройки клиента по умолчанию: `timeout=5` секунд и `retries=1`.
Параметры хранятся в клиенте как настройки будущего транспорта; ожидание и
повторные запросы в этом примере не реализованы.

Сервис получает статус записи, а worker формирует результат задания.
Из каталога этого проекта пример запускается командой:

```powershell
python worker.py
```

Зависимостей вне стандартной библиотеки Python нет.
